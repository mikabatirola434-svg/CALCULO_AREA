# CALCULOAREA

## Descripción

Este proyecto fue realizado para la materia Laboratorio de Programación.

El programa calcula el área de un círculo utilizando una función modular en C++.

## Objetivo

Aplicar el enfoque Top-Down y la programación modular mediante el uso de funciones.

## Funcionamiento

El programa solicita al usuario el radio de un círculo en centímetros.
Luego valida que el radio sea mayor que cero, calcula el área y muestra el resultado en pantalla.

También muestra una representación de una diana en la consola dependiendo del radio ingresado.

## Fórmula

Área del círculo:

A = π × r²
